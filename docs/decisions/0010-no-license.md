# 10. No open source license

- Status: Accepted
- Date: 2026-11-25

## Context

The repository is public so people can look at the code. The app itself is only meant for my own use (ADR 0003).

## Decision

The repository has no license. All rights reserved: you can read the code, but not reuse or host it.

## Consequences

- The README says so.
- I'm not expecting outside contributions.
- I can still add a license later.
